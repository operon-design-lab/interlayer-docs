# Current beta limitations

The following are **not available** in the current beta. Do not plan a setup that depends on them.

| Not available | Notes |
|---|---|
| Automatic Profile / Layer switching by the app in front | Switch with Commands, the RUN Menu or the ••• controls. |
| Sending keys to an app that is not in front | Keyboard, Mouse and Text act on the frontmost app / focused field. |
| Moving the mouse pointer to coordinates, or dragging, from a Command | Mouse acts at the current pointer position. |
| Several key presses or held keys in one Keyboard Command | Use a Multi Action for sequences. Keys outside the documented list (for example F13 and above) are not supported. |
| Long press, hold, double tap and multi-finger gestures as triggers | Only Touch Release and Touch Down. |
| Loops, conditions and variables in Multi Actions; nested Multi Actions | — |
| Variables or templates in Text Commands | Text is fixed. |
| Creating Commands with your own States (toggles) | Plugin toggle Commands have States. |
| Changing a Part's type after adding it | Add a new Part. |
| Exporting a whole Project as one file; cloud sync | Export Profiles or Packs, or copy the Project folder. |
| Windows or Linux | macOS (Apple Silicon) only. |
| Intel Macs | Apple Silicon only. |
| Built-in AI features | InterLayer does not generate Commands, icons or images. |

Sidecar touch input is supported, but touch behaviour with external USB touchscreens has not been documented for this beta.
