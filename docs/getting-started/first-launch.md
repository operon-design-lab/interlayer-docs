# First launch

## 1. Choose a folder for your Project

The very first time InterLayer starts, it asks you to **Choose a Folder for Your Project**.

- **Choose an empty folder** (or create one with **New Folder**) to start with the InterLayer starter Profiles. InterLayer copies a starter Project into it.
- **Choose an existing Project folder** to open it as it is.

If you cancel, InterLayer stays open without a Project and shows *No Project open*. You can open one later from the menu bar: **InterLayer ▸ Open Project…**.

After the first launch, InterLayer reopens the last Project automatically.

> A *Project* is a folder that holds one InterLayer setup. Studio calls the same folder a *Workspace*. See [Concepts](../user-guide/concepts.md).

## 2. What you get

The starter Project contains three Profiles:

| Profile | What it is |
|---|---|
| **Launcher L(Default)** | A larger launcher panel (shown first). |
| **Launcher S(Default)** | A smaller launcher panel. |
| **Music(Default)** | Controls for Apple Music. |

InterLayer also adds starter content to your Library. It is yours to edit:

- Command Packs: **Keyboard**, **Mouse**, **macOS Shortcuts**
- Icon Packs: **Keyboard Glyphs**, **Standard Icons**
- Designs: **Minimal Dark(Default)**, **Minimal Light(Default)**, **Minimal Solid Dark(Default)**, **Minimal Solid Light(Default)**

Starter content is installed only once. If you delete a starter Pack, it is not reinstalled, and updates never overwrite your copies.

## 3. The RUN overlay appears

InterLayer starts with **RUN**: the control panel that floats above your other apps. Click or touch a Part (a button, slider or dial) to run its Command.

## 4. Allow Accessibility

The first time a Command sends keys, mouse clicks or media keys, macOS asks you to allow InterLayer in **Accessibility**. RUN collapses for a moment so the macOS prompt is not hidden behind it. See [Permissions](permissions.md).
